# Employee App

A simple Kotlin employee payslip application created for the Software Development Tools module.

## Features

- Displays employee details
- Calculates normal pay and overtime pay
- Calculates gross pay
- Calculates bonus, tax and pension deductions
- Calculates net pay
- Displays a full payslip
- Provides a simple menu for selecting options

## Technologies

- Kotlin
- Gradle
- IntelliJ IDEA
